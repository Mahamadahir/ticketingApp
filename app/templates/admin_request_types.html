Request types

The things people can ask IT for, listed on the request form (New starter, Software install ...). Each points at an approval group (Admin > Approval groups) whose members vote on the request before the work goes ahead. "Percent to pass" is the share of the voters that must approve, rounded up (5 voters at 60 needs 3; 100 means everyone). The request is declined as soon as that can no longer be reached (5 voters at 60: a third decline closes it). The voters are the group's members when an agent triages the request, minus the requester. "Offer a Required by date" lets the person raising the request give a date; it then replaces the SLA resolution target for that request and the queue ranks it from the lead time (Admin > Settings) before that date. An available type needs a group with at least one member. Switching a type off hides it from the form; tickets already raised keep it.
