Request types

The things people can ask IT for, listed on the request form (New starter, Software install ...). Each can have approvers: people with an account (they sign in once first; they need not be agents, managers are typical) who will approve the request before the work goes ahead. Up to {{ max_approvers }}. "Approvals needed" is how many of them must approve (1: any one approver is enough); "declines" is how many must decline to close the request. If so many decline that the approvals can no longer be reached, it closes too. The request waits in Awaiting approval, starting when an agent triages it. Switching a type off hides it from the form; tickets already raised keep it.
