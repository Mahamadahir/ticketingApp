Outage mode

For when Microsoft (Entra) sign-in is down. While it is on, agents can sign in on the sign-in page with the emergency password they set in advance, and every page shows a banner. Only a break-glass account can switch it on; any super admin can switch it off. Switching it off ends every emergency session, clears every emergency password that was used during the outage and emails those agents asking for a new one. Every switch is audited and tells the super admins.
